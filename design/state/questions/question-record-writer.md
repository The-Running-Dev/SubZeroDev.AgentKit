# question/question-record-writer
Status: open

## Text
Which command writes a question record, and when — `design/10-design.md` § *Record* gives a five-step flow for a decision and the design has no question equivalent. `/track` already reads `## Open` and already distinguishes a question from a task, which makes it the obvious writer and also crosses the tracker-writes boundary `AGENTS.md` draws around it; the session that notices the question is the second candidate, with no single command to name and therefore no surface to contract; a record written only where a unit's `Questions` field needs a referent is the third, which makes it `/slice`'s and leaves questions nobody is blocked on unrecorded. Each choice changes a different command file.
