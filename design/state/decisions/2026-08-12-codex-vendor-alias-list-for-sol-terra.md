# decision/2026-08-12-codex-vendor-alias-list-for-sol-terra
Date: 2026-08-12
Anchor: 2026-08-12 — Codex's own model names (`Sol`, `Terra`) recognized via a vendor alias list, not the primary tier table
Status: accepted

## Claim
Codex's own model names are recognised via a new `Vendor model aliases` subsection under the tier table — `Vendor | Reported as | Tier` — seeded with Codex/`Sol`/Deep reasoning and Codex/`Terra`/Implementation, rather than adding columns to the primary tier table. A name in the list is a synonym for an existing tier; a reported name in neither the table nor this list is a real mismatch and the gate stops on it.
