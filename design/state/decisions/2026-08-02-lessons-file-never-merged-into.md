## Claim
Where a target already has a lessons file with content, it wins wholesale and the kit's seed is not merged in. Individual kit lessons are offered one at a time, only where the target's file is silent on the point and the lesson applies; a kit lesson already present in more detail is treated as having originated there and dropped silently.
