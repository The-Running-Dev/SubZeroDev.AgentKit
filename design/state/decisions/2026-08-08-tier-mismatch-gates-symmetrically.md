Date: 2026-08-08

Status: accepted
StatedIn: "unit/document/agents-md § Model, effort, and review budget"

## Claim
A tier mismatch in either direction stops before expensive work, names the tier the task actually needs, and waits for an explicit override — over-powered names the lighter tier that fits, exactly as under-powered names the stronger model needed. Because the session model cannot change mid-session but reasoning effort can, the override for an over-powered mismatch may be capping reasoning effort rather than a model swap.
