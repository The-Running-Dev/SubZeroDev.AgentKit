## Claim
`AGENTS.md` § *Output discipline* is the single rule for what a session reports and pulls into its context. A routine completion report carries what changed, what actually ran, and a material risk. Durable artifacts are named rather than reproduced. Required evidence is never shortened. A subagent is justified by independence or containment and returns facts, not narrative. Commands cite the rule rather than restating it. Output is measured only in fields a Claude Code transcript states exactly, counting each response once. Codex's output and context keys are recommended base configuration, not launcher-enforced.
