## Statement
`tools/Test-Companion.ps1` reports `Valid` for a companion's `tightened-authorization` override
only when every non-blank line under it is an `ask-before` entry naming an action its core's block
lists as performed without asking. Any other line, and any action outside that list, is `Invalid`,
so an override that widens an authorization cannot pass — it has no form in which to be written.
