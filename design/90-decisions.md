Leaving that sentence alone would have left the contract contradicting the procedure, which is the defect this repository's own § *Source of truth* exists to stop.
Rejected: **Leave `/install-all` matching it** — an unattended pass over every `SubZeroDev.*` sibling would open a pull request per repository faster than anyone can read them, on targets whose forks that pass has already declined to answer; `install-all.md` now names this as its one deliberate tightening of `INSTALL.md`'s list rather than claiming the lists are identical. **Relax `/install-code-review-agent` too** — its stop is on its own reason, not `/install`'s: it writes a workflow that grants CI a repository secret, and the App install and secret are the user's own actions, so landing the file before they exist ships a workflow that cannot run. Its cross-reference to `/install` was corrected to stand on that reason instead. **Make delivery opt-in per run** — a flag nobody passes is the old behaviour with extra steps, and phase 3's sign-off already gates the whole install, so a post-sign-off commit lands approved work rather than assumed work. **Commit but stop before the PR** — keeps the diff off any review surface, which is the failure being fixed.
Reversibility: cheap for the prose; the widened carve-out is a policy change, and reverting it means every install ends in a hand-finished worktree again.

### 2026-08-26 — `Update-WorkMirror.ps1` writes a `WorkRef` only when a mirrored field changed
Context: Issue #127. `design/20-contract.md` § *Public surface* required `Update-WorkMirror.ps1` to stamp `MirroredAt` on every write "including a write that changed nothing", and `MirroredAt` holds the current commit sha. That made a mirror's content a function of repository history rather than of tracker state: any commit to the default branch — including `/track`'s own previous mirror-refresh commit — made the next `/track` run see a diff consisting solely of the stamp. `AGENTS.md` § *Git and delivery* forbids work landing on the default branch, so that diff forced a branch, a pull request, a merge, and a `/clean` pass, whose merge commit then guaranteed the next run would do it again. Observed on 2026-08-26: a refresh, PR #125 merged, `/clean` run, and the immediately following `/track` produced an identical-shaped diff with nothing else touched. `/contract` was the escalation target the issue named.
Chosen: The write becomes conditional on content. `Title`, `State`, `Criteria` and `Rank` are the mirrored fields; `MirroredAt` is not one of them and never triggers a write by itself. A run over an unmoved tracker leaves every record byte-identical, reports that it changed nothing, and produces no commit — so the loop has no diff to start from. `MirroredAt` keeps its type and its stamping rule unchanged for writes that do happen, and now dates the mirror's *content* rather than the tracker's last consultation. `MirrorStale`'s comparison is untouched and still fires for every record the current commit did not write, so a mirror remains stale by default and still says so. The contract's `MirroredAt`-is-never-omitted clause and I28 are both unaffected.
Rejected: **Exempt `WorkRef` writes from the per-commit branching rule** — kills the loop without touching the tool and preserves the "we checked at this commit" honesty the old clause was for, but carves a hole in the one rule `AGENTS.md` states without exception, and a hole defined by which files a commit touches is one a later commit widens by accident. It also lands on `unit/document/agents-md`, whose closure has 349 bytes of headroom against a decision record of roughly 690 — recording it would be a blocking `ClosureOverBudget` finding under I23. **Accept the round trip as the documented cost of "stale by construction"** — relitigates nothing and is honest, but leaves a loop that runs on every `/track` invocation forever and produces pull requests whose entire content is a sha; it lands on `unit/document/design-20-contract`, 217 bytes of headroom, and is unrecordable for the same reason. **Change what `MirroredAt` stamps, or how `MirrorStale` judges staleness** — the broader reading of the same fix; rejected as unnecessary, since the loop is caused by writing on every run rather than by the stamp's meaning, and the narrow fix leaves every existing term about that meaning standing.
Known and retained: a checkout can no longer say when `/track` last *looked*, only when a mirrored field last *changed*. Accepted: `MirrorStale` has never blocked, and GitHub is authoritative for anyone who can reach it.
Reversibility: cheap — one bullet in § *Public surface*, one `Semantics` line, and one condition in the script.
